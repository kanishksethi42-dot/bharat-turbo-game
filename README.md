# Bharat Turbo — GTA India

A browser-based 3D open-world driving game built with React, Three.js, Vite, Express, and WebSockets.

## Run locally

- Node.js 22+
- `npm install`
- `npm run dev`

## Production

- `npm install`
- `npm run build`
- `npm start`

The Express server serves the production build and provides API and WebSocket endpoints. See `render.yaml` for the Render service configuration.
